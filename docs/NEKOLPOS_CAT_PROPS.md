# NEKOLPOS 追加3D小物（猫用品） — dot制作ブリーフ v0.1

対象：猫じゃらし、小型ブラシ、大きめのキャットタワー。所有者の依頼に基づく**制作候補ではなく発注済みの作業**。ただし、細かなデザイン・材質・サイズは**初回ラフを見て決める**。色や飾り、段数をこちらで勝手に確定しない。

## 共通条件
- [3D共通仕様](3D_ASSET_SPECS.md)に従う。小人（身長約5cm）が至近距離まで接近する想定。
- 無駄なハイポリ化を避け、近距離から見える輪郭・厚み・素材感を成立させる。
- 猫が日常的に使った**経年感**を付ける。ただし極端な汚れ・破損は不要。
- Blender編集可能なデータとUnity向けモデル、材質・テクスチャ、全周＋小人視点プレビューを納品する。
- 最初はラフモデルを提示してオーナーのレビューを受ける。機能や動くアニメーションは**別途依頼があるまで作らない**。
- 既存NEKOLPOSアセットの重複を調査する。dotが実制作を進める際、作業環境・権限・ファイル保存先を確認する。
- 参考にする製品画像は**未指定**。dot側から外観案・必要な確認事項を提案してよいが、最終確定は所有者レビューによる。

## CAT-PROP-01 猫じゃらし
- 持ち手・棒・紐（または連結部）・猫の注意を引く先端の飾りが識別できる**猫じゃらしを1点**制作する。
- 先端は飾りを独立メッシュにするなど、将来揺らす／持ち上げるモーションを加えられる構造を推奨。**骨・物理シミュレーションは今回必須ではない**。
- 使用感：持ち手の擦れ、軽く乱れた先端飾り等を自然な範囲で検討。
- 紐と飾りの形・素材・長さは初回ラフの候補として提案。
- **受入条件**：静止モデル、持ち手・飾り・連結部を確認できる近接画像、編集可能な元データ、Unity向けモデル。

## CAT-PROP-02 小型ブラシ
- **小型ブラシ1点**を制作。用途は猫用グルーミングブラシを仮の方向性とするが、具体的なブラシ形式（スリッカー、柔毛、手持ちミニブラシ等）は未確定。
- 持ち手、ブラシ面、毛／ピン／突起の存在が小人視点で識別できる形状にする。
- 毛／ピンを全本数高ポリ化しない。**まとまり＋少量の立体表現・マテリアル**を併用して負荷を抑える。
- 少し使用した質感を付ける。毛が絡まった不潔な表現を必須としない。
- **受入条件**：近接でブラシと判別できる静止モデル、元データ、Unity向けモデル、素材分割・負荷配慮の説明。

## CAT-PROP-03 大きめのキャットタワー
- **大きめで存在感のあるキャットタワー1基**を制作。猫が乗って休める家具として自然なスケール感を最初のラフで提案する。
- 参考構造案：広い台座、複数の柱と足場、爪とぎポール、寝る場所。**段数・全高・付属ハウスは未確定**。最初は1案を出し、所有者が調整できるようにする。
- **猫の体格で利用できる足場・幅・間隔**を確保し、床の設置面や安定感も考慮する。
- 5cmプレイヤーが近くへ寄れるので、ロープ巻き、布の縫い目、摩耗した爪とぎ跡を破綻しない程度に表現する。繊維や紐を全てポリゴンで実体化する必要はない。
- 主要な台座・支柱・ステップ・寝床を別部品にし、Unityのレイアウト変更に対応しやすくする。**プレイヤーの登攀ギミックは未確定なので実装不要**。
- **受入条件**：全体シルエット、猫の使用を想定した各段、5cm視点の近接プレビュー、編集可能な元データ、Unity向けモデル。
