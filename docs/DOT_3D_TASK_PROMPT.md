## 特に守る条件

1. **小人（身長約5cm）が至近距離に近づく**ゲームなので、過剰なハイポリ化なしで、縁、継ぎ目、穴の内部、登れる場所などの近接形状を丁寧に作る。
2. **新品に見せない**。日常生活での自然な経年使用感を適度に付ける。
3. **自動給餌器は白色電動式**。給餌口を**実際に侵入できる横穴**にする。タンクには**餌テクスチャ用の下降可能な別メッシュ**を設ける。皿のカリカリは群メッシュ＋個別に持てる粒を組み合わせ、無理に全粒独立させない。
4. **自動給水器は白い水道直結式**。添付参考画像の右側の本体と左側の湧出構造を合わせる。**常に流れて見える水**の簡易表示が必要。小人が上に登れ、水の中に入れる構造・分割を確保する。
5. **見た目と将来拡張用の構造までが今回の範囲**。餌を出すタイマー、粒の拾得処理、詰まり解消のゲームイベント、ポンプや水の物理シミュレーション、泳ぐ操作などは作らない。
6. **各モデルは別タスク**として進める。まず小さなラフ・近接プレビューを提出し、所有者のレビューを受けてから作り込む。
7. ブランドロゴ、広告文言は転載しない。参考の外観からゲームで使える独自モデルにする。

## 資料と環境の確認

- この公開GitHubリポジトリには**参考画像そのものは入っていません**。**所有者がこの会話で提示した参考画像2枚を、dotの作業環境でも参照できるように共有してもらってください**。
- Blender／Unityを本当に使用できるか、プロジェクトの所在、モデルの取り込み規格、既存アセットとの重複を確認する。
- UnityのPlayer Collider・移動要件がわからない場合、内部通路や水受けの寸法を仮と明記してラフを見せる。
- 既存NEKOLPOSリポジトリを無断で破壊的変更しない。
