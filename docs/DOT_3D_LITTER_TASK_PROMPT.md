## 必須要件

1. **全体は白系のドーム形・丸みのある本体＋下部ベース**。使い込まれた生活用品として軽い擦れやくすみを付ける。ただし清潔さは維持。
2. プレイヤーは**身長約5cm**。極端な高密度ポリゴンは不要だが、入口の厚み、内壁、底面、境界、部品の段差は至近距離でも形状として成立させる。
3. 猫が実際に中に入れる大きさの、**奥行きのある内部空間**を作る。入口だけで黒く塞がない。
4. **猫砂を粗く描写**。ベースとなる砂面メッシュ＋ノーマル／粗い凹凸と少量の立体粒等で十分。全砂粒の個別化や物理シミュレーションは避ける。
5. **回転体と固定ベースを別Objectにする**。回転ピボットを整え、ラフで**通常姿勢と2枚目を参考にした回転後の姿勢**を見せる。回転方向・軸・角度は画像だけで確定できないため仮案を明示し、レビューで決定する。
6. **正面右下に動かせるスイッチ**を置く。少なくとも独立した立体Objectにして、可動軸・支点を調整できるようにする。スイッチの種類（押し込み、トグル等）はラフで提案し、勝手に確定しない。ベース側を初期案とする。
7. 内装、回転体、固定台座、猫砂、スイッチを用途ごとに分離し、将来Unityで制御・コライダー調整しやすい構造と命名にする。

## 進行

- 既存NEKOLPOSアセット、Unityスケール、プレイヤーや猫のColliderを可能な範囲で確認。
- **最初はBlenderでラフモデルを制作**。オーナーに通常時・回転参考姿勢・開口部内側・猫砂・右下スイッチ・小人視点の近接プレビューを提示。
- 所有者のレビュー後にディテールと経年使用感を調整。
- 編集可能な制作元データ（例：.blend）、Unity向けモデル（例：.fbx）、マテリアル・テクスチャを納品。
- Unityでのインポートや回転・内部の検証結果は、実際にできた範囲のみ報告。

## 第一段階の対象外

- 清掃アルゴリズム、排泄物処理、回転アニメーション本実装
- スイッチ操作に反応するゲーム処理、猫の出入りアニメーション
- 砂粒の完全個別化・物理演算、未指定の複雑な内部機構

**重要：まだ完成品の3Dモデルや実際の回転機能を要求しているのではなく、レビュー可能なモデルと、将来回せる構造を先に用意する依頼です。** 画像を見られない・Blenderを使えない場合は推測で完成扱いせず、障害を報告してください。
